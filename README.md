少量贴图来自于SPBR资源包，作者Shulker \n
如果你不知道这是什么：这是一个Minecraft的资源包，它提供了一些模组方块的PBR效果（提供反射、凹凸等效果） \n
目前覆盖率介绍：
热力扩展：几乎全方块全机器覆盖，全部机器动态效果和高光全覆盖，部分不常用的设备（例如知识聚集器）暂且使用程序生成的PBR，这部分较粗糙
匠魂扩展：几乎全方块覆盖；鉴于“部件”贴图过多（上千），这部分高光和法线是AI代劳的；部分纹理来自于SPBR，例如焦黑砖块——石砖等
暮色扩展：只做了极少量的方块，包括无头骑士的迷宫砖块、米诺陶的迷宫砖块等
